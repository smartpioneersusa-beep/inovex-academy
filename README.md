# INOVEX Academy portal

Static front end for **academy.inovex-group.com**. Course content is never stored here — it is served only to signed-in trainees by the INOVEX Academy API (Google Apps Script on info@inovex-group.com).

- `index.html`, `styles.css`, `app.js`, `i18n.js` — the portal (English, Arabic, Urdu, Hindi)
- `config.js` — API address
- `CNAME` — custom domain for GitHub Pages

Courses authorised by Wagner Group · in association with Al Qemma Academy.
